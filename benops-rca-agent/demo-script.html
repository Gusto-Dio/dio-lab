BenOps RCA Agent — Demo Script

Hackathon presentation · ~3 minutes · Live on GSTO-FR5-APP002

Set the Stage
~30s
"Today, when a benefits enrollment bot fails in Orchestrator, an engineer has to investigate manually — reading logs, reviewing XAML code, checking PR history. That takes hours. And depending on the ticket queue, the enrollment can stay broken for days — meaning the employee doesn't have their health coverage."
  • Show Orchestrator dashboard with a running (or recently faulted) job
  • Keep it brief — the pain is familiar to everyone in the room
0:30
2
Trigger the Failure
~20s
"Let me show you what happens now. I'm going to trigger a bot run that will fail — same kind of failure we see in production."
  • Trigger test job in Orchestrator (process configured to fail with a known error)
  • Show job status changing to Faulted — let judges see it happen live
  • Start the RCA Agent script in the VM terminal

Land the Impact
~30s
"What just took 47 seconds used to take 2+ hours of manual investigation — and the ticket would sit in the queue for days before anyone even looked at it. With the RCA Agent, the engineer receives a pre-diagnosed ticket and goes straight to the fix. Enrollments that were broken for a week now get resolved the same day."
