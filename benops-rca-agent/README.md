# BenOps RCA Agent

**Event:** Benefits Hackathon — June 2026  
**Team:** BizTech RPA  
**Status:** In progress

Autonomous Python agent that detects Faulted jobs in UiPath Orchestrator, collects execution logs + XAML source + PR history, sends context to the Claude API for root cause analysis, and delivers a pre-diagnosed Jira ticket + Slack alert in under 60 seconds.
